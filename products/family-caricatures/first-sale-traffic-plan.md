# First-sale traffic plan — Family caricatures (fleet task #147)
Product: Family caricatures (custom family portraits/caricatures from customer photos, Etsy) · Role: optimizer · 2026-10-13
All market figures from live Etsy pages, 2026-10-13. Fee schedule: Etsy's current published fees.

## Where the first 10 buyers come from

**Target Etsy search terms** (most-repeated title keywords across top listings — use in title + tags):
custom, family, caricature, portrait, personalized, from photo, cartoon, gift, digital, group.
Long-tail to own early: "custom family caricature from photo", "family cartoon portrait gift", "personalized family portrait digital".

**Market context:** digital family caricatures sell at $10–$65 (observed: $12.00–$63.50, large-group tiers to $97.50); best sellers run near-permanent 20–50% sales, hold 4.8–5.0 stars with hundreds–thousands of reviews, Star Seller badges, and tiered per-person pricing. Physical prints run $25–$100+. New listings get zero organic rank — the first buyers come from seeding + paid, not search.

## Ads decision with fee math

**Etsy Offsite Ads: ON is mandatory, not a choice.** New shops (under $10k/12mo) cannot opt out — sales attributed to offsite ads cost 15%. So the decision is to price to absorb it, not whether to run it.

**Etsy Ads (on-site, optional CPC): ON at a small test budget.** New listing + zero reviews = no organic visibility. Set $2–3/day for the first 30 days (~$60–90 total test spend). Kill it if ad-attributed ACoS exceeds 30%; scale it if a listing converts.

**Fee math — worked example at $39.99 digital** (mid-band; adjust when launch price is set):

| | Amount |
|---|---|
| Sale price | $39.99 |
| Listing fee | −$0.20 |
| Transaction fee 6.5% | −$2.60 |
| Payment processing 3% + $0.25 | −$1.45 |
| **Net, organic sale** | **$35.74** |
| Offsite-ads fee 15% (if attributed) | −$6.00 |
| **Net, offsite-ad sale** | **$29.74** |

Digital = no COGS, so contribution is the net above minus artist time. At $39.99 even an offsite-ad sale keeps ~74% of price. Rule: never discount below $29.99 during launch — that floor still nets ~$22 on an offsite sale.

## Concrete seeding steps (first 10 buyers)

1. **Portfolio orders (buyers 1–4):** offer 3–4 caricatures at $10 "portfolio price" to friends/family this week. Goal: finished samples for the gallery (#144) + first reviews. Ask each for an honest review on delivery.
2. **Launch sale (buyers 5–10):** list at $39.99 with a 30% launch sale ($27.99 — still above the $29.99 floor... set sale price $29.99 exactly) for the first 30 days, matching the market's permanent-sale pattern.
3. **Etsy Ads on** at $2–3/day from day one; review weekly.
4. **Christmas gift angle:** Q4 is gift season — position as "the Christmas gift for the family that has everything" (coordinates with #148 holiday positioning). Add "christmas gift" to tags in November.
5. **Community seeding (with permission, no spam):** local parenting Facebook groups, neighborhood groups — one genuine post offering the launch discount; Reddit r/GiftsForHer / r/christmasgifts only where self-promo is allowed.
6. **Review engine:** message every buyer 3 days after delivery asking for a review; reviews are the ranking fuel that replaces ad spend.
7. **Referral loop:** give each buyer a 20%-off code for friends — buyers 5–10 become the source of 11–20.

## What success looks like
10 sales in the first 45 days: 4 portfolio + 6 full-funnel (ads + sale + community). At that point the listing has reviews, a gallery, and conversion history — organic Etsy search starts carrying weight and ad spend can taper.
