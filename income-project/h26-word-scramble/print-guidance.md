# Halloween Word Scramble — Print Guidance (actual-file version)

## Quick Print Instructions

1. **Download** the PDF file after purchase
2. **Print** on US Letter paper (8.5" × 11") at 100% scale
   - Do NOT select "Fit to page" or "Shrink to fit" — use "Actual size"
3. **Page 1** is the game sheet — hand out to players
4. **Page 2** is the answer key — keep for the host

## Tips

- Works on any home inkjet or laser printer
- Standard copy paper is fine; cardstock gives a nicer feel for parties
- Print in black & white or color — the game is readable in both
- Each print makes one game set — print as many copies as you have players

## File Details (verified against the accepted source)

- Format: PDF, 2 pages, US Letter (612 × 792 pt)
- All vector text — crisp at any print resolution; resolution/bleed do not apply
- Fonts: Helvetica family (not embedded — low risk)
- Both pages carry the line "Printable game — personal use. Print on US Letter."
- Personal use only
