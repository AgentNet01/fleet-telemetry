# Research Finding Template

Every area owner: write your file using exactly this shape so the 12 findings merge cleanly.

## Area
<one line>

## Problem
What swarm problem does this area solve? 2-4 sentences, concrete.

## Options considered
| Option | Upside | Downside |
|---|---|---|
| | | |

Minimum 2 options. Include "do nothing / keep current" as one.

## Recommendation
What the fleet should do. Specific, not "consider X".

## What to build / change
Concrete artifacts: files, repo changes, cron changes, new tools, config. Checklist form:
- [ ] ...

## Open questions
Things you could not resolve — flag for the group, don't hand-wave.
